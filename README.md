# Crown Barber Studio – Business Website

Sitio web moderno para una barbería premium, diseñado como proyecto de portafolio y pensado para un posible uso comercial real.

El objetivo del proyecto fue crear una web atractiva, clara y enfocada en conversión para negocios locales como barberías o peluquerías.

## 🧠 Descripción

Crown Barber Studio es un sitio web de una sola página diseñado para una barbería moderna.  
Incluye secciones típicas de un negocio local como servicios, galería, reseñas, ubicación y contacto.

La página está optimizada para dispositivos móviles y facilita la reserva de horas mediante WhatsApp.

---

## ✨ Características

- Diseño moderno estilo premium
- Layout completamente responsive
- Sección de servicios con precios
- Galería visual de trabajos
- Reseñas de clientes
- Mapa de ubicación integrado
- Botón flotante de WhatsApp
- Navegación adaptable a móvil
- Animaciones al hacer scroll

---

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Flexbox / Grid
